# Eng. Abdulrahman Abu Eisha — Portfolio Frontend

Modern, responsive personal portfolio built with **React**, **Vite**, and **Tailwind CSS**, consuming a **Laravel REST API** backend.

## Live Demo

[eng-abdulrahman-abu-eisha.vercel.app](https://eng-abdulrahman-abu-eisha.vercel.app)

## Tech Stack

- **Framework:** React (Vite)
- **Styling:** Tailwind CSS
- **Deployment:** Vercel

## Local Setup

1. Clone the repository:
   ```bash
   git clone [https://github.com/abueshia/eng-abdulrahman-portfolio-react.git](https://github.com/abueshia/eng-abdulrahman-portfolio-react.git)
   cd eng-abdulrahman-portfolio-react
   ```
